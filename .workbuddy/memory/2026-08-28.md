## 第五章"no such column: name"排查（非应用 bug）
- 用户 SQL：`SELECT name, city WHERE name LIKE '%科技%';` —— 缺少 `FROM customers`。
- SQLite 允许无 FROM 的 `SELECT ... WHERE ...`，因此报 `no such column: name` 而非语法错误，误导性强。
- 已用项目自带 sql.js 复现验证；正确 SQL `SELECT id, name, city FROM customers WHERE name LIKE '%科技%';` 返回 3 行（星河科技/远山科技/澜海科技服务）。章节定义（chapters.ts id:5）与 schema/seed 数据均无问题。
- 潜在改进（未实施，待用户确认）：SQL 报错为 "no such column" 且语句缺 FROM 时，给出友好提示。
